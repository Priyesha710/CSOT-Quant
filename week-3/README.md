# CSOT Quant Finance & Research

Welcome to the CSOT Quant Finance & Research repository.

This repository hosts weekly quantitative finance challenges focused on alpha
research, portfolio construction, and systematic trading. Each week introduces a
new problem along with the data, starter code, and rules needed to participate.

## Week 3

Participants are required to build a market-neutral long-short equity portfolio
using technical and volume-based features derived from daily price/volume data.

Evaluation is based on Net Sharpe Ratio while satisfying portfolio constraints.
